# 國貿自習室

國貿丙級學科與術科的本機練習網站。預載 6 題自編示範題及 4 個示範章節。示範參考答案與官方答案分開儲存，預載內容未引用法規條文。

## 啟動

需要 Node.js 22.13 以上與 npm。使用 PDF 匯入時，另需安裝 Poppler，確認終端機可執行 `pdftotext -v`。CSV 和其他功能可直接使用。

```sh
npm ci
npm run dev
```

開啟 <http://127.0.0.1:3000>。本機資料儲存在 `data/study.sqlite`，重新開啟會保留。可設定 `TRADE_DB` 指向另一個 SQLite 檔。正式建置以 `npm run build` 驗證，並以 `npm start` 啟動。

## 分階段驗收

| 階段 | 測試操作 |
|---|---|
| 學習介面 | 開啟「章節重點」並練習本章。到「題庫練習」測試年度、甄試名稱、科目、主題。自編題的年度為「未提供」。交卷後確認自編題顯示「示範參考答案」。 |
| 練習紀錄 | 收藏一題，故意答錯後交卷，從錯題清單重練。答對後確認錯題清單移除該題，作答紀錄仍保留兩次結果。從模擬考設定一分鐘，作答後重新整理，觀察倒數與自動交卷。 |
| 題庫管理 | 匯入 `samples/questions.csv`，分別預覽兩筆並發布。回題庫確認兩份甄試名稱、題號及重複標記都保留，模擬考去重後只計入該群組一次。匯入 `samples/questions.pdf` 時，從校對欄將其標為自編題，修正科目、主題及題型，再填入示範參考答案。 |
| 建置與回歸 | 執行 `npm test` 與 `npm run build`。以桌面視窗及瀏覽器的手機尺寸檢查選單、篩選、作答、交卷及管理。 |

## 匯入與評分

- CSV 使用 UTF-8，首列為欄位名稱。`samples/questions.csv` 提供可編輯的範例。選項用 `|` 分隔，選擇題答案為從 1 開始的選項序號。管理頁可補齊其餘欄位。
- PDF 擷取文字層，依頁面與辨識到的題號建立草稿。擷取規則是通用起點，遇到跨頁、多欄、表格或圖片時，請對照原卷。PDF 一律先作為待校對項目，答案欄保持空白。
- 管理者在發布歷屆題前填寫重製依據與日期，確認已對照原卷與使用條件。官方答案與來源成對記錄。缺原始試卷網址或官方答案的項目在題庫資料與結果頁標示，缺官方答案的題目不納入評分。
- 數字題按數值比對，文字題按正規化後的文字比對。自我核對題提供參考答案並計為未評分；已評分但未作答的題目計為答錯。編輯並重新發布會增加題目版本，歷史評分使用當時的版本。
- 重複題經人工確認後填入同一群組代號。題庫各自保留來源，模擬考對符合篩選條件的題目依群組去重。

## 瀏覽器版

`web/` 是上線版本的前端原始碼，包含最新五大考科章節、章節練習，以及在瀏覽器中處理 PDF／CSV 和儲存作答紀錄的功能。部署後可直接用瀏覽器開啟。

開發時可在 `web/` 執行 `npm ci` 與 `npm run build`，產生靜態網站至 `web/dist/`，再用靜態網站伺服器提供該目錄。
